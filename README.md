# Luso·Math 🇲🇿🇦🇴

**ポルトガル語 × 高校数学（文系）× アフリカ近現代史**を一緒に学べる、ブラウザだけで遊べる学習ゲームです。

🌆 見た目は **80sシティポップ／レトロポップ** 調（サンセット・グラデーション＋ネオングリッド＋ピクセルフォント）。
🎵 **BGM付き**（右上の 🔊 ボタンでオン／オフ。設定はブラウザに保存されます）。

ビルド不要。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

1. `index.html` をダブルクリック（またはブラウザにドラッグ＆ドロップ）して開く。
2. 2つのキャンペーンから選ぶ：
   - **🇲🇿 モザンビーク編** … 数学Ⅰ・Ⅱ ＋ モザンビーク近現代史 ＋ ポルトガル語
   - **🇦🇴 アンゴラ編** … 数学A・B・C ＋ アンゴラ近現代史 ＋ ポルトガル語
3. 章を選ぶ → 「この章のポイント」で予習 → クイズに挑戦。
4. 各章は **ポルトガル語 → 歴史 → 数学** の順に出題。半分以上正解で次の章が解放されます。

進捗はブラウザの `localStorage` に保存されます。

## 学べる内容

### 数学（文系範囲）

| 編 | 単元 |
| --- | --- |
| モザンビーク（Ⅰ・Ⅱ） | 数と式 / 二次関数 / 図形と計量（三角比）/ データの分析 / 指数・対数 / 三角関数 / 微分・積分 |
| アンゴラ（A・B・C） | 場合の数と確率 / 整数の性質 / 数列 / 統計 / ベクトル / 複素数平面 |

### 歴史

- **モザンビーク近現代史**：ポルトガル植民地 → FRELIMOの解放闘争 → 1975年独立（サモラ・マシェル）→ 内戦（vs RENAMO）→ 1992年ローマ和平協定。
- **アンゴラ近現代史**：奴隷貿易と植民地 → MPLA/FNLA/UNITAの三つ巴 → 1975年独立（アゴスティーニョ・ネト）と冷戦の代理戦争 → 2002年まで続いた内戦 → 石油による復興。

### ポルトガル語

あいさつ・数（数学の問題にも登場）・自由／平和／独立／選挙などの歴史キーワードを、文脈の中で学びます。

## ファイル構成

```
index.html              エントリーポイント
css/style.css           スタイル（80sシティポップ）
js/game.js              ゲームエンジン（画面遷移・採点・進捗保存）
js/audio.js             BGMコントローラ（再生・ミュート保存）
js/data/mozambique.js   モザンビーク編の問題データ
js/data/angola.js       アンゴラ編の問題データ
assets/bgm.mp3          BGM（ループ再生）
```

### BGMについて

`assets/bgm.mp3` をループ再生します。差し替えたい場合は同名のmp3を置くだけでOKです。
多くのブラウザは音声の自動再生を制限しているため、**最初のクリック（タップ）で再生が始まります**。
右上の 🔊 / 🔈 ボタンでいつでもオン／オフを切り替えられます。

## 問題を追加・編集する

`js/data/*.js` の各ステージ `questions` 配列に、次の形式で追加するだけです。

```js
{
  type: "math",            // "lang"（言語）/ "hist"（歴史）/ "math"（数学）
  subject: "数学Ⅰ・二次関数", // type:"math" のとき表示される科目名（任意）
  q: "問題文",
  options: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: 1,               // 正解の options インデックス（0始まり）
  explain: "解説文",
}
```

エンジン側のコードを触らずにコンテンツを増やせる設計です。
