# Luso·Math 🇲🇿🇦🇴

**ポルトガル語 × 高校数学（文系）× アフリカ近現代史**を題材にした、
ブラウザだけで遊べる **シリアスなノベルゲーム**です。

失われた歴史記録を復元する見習いとして、案内人（現地の老アーキビスト）とともに、
ポルトガル語を読み解き、歴史を確かめ、記録の数字を計算（数学）しながら、
モザンビークとアンゴラの近現代史をたどり直します。

- 🌆 見た目は **80sシティポップ／レトロポップ** 調（サンセット＋ネオングリッド＋ピクセルフォント）
- 🎵 **BGM付き**（右上の 🔊 ボタンでオン／オフ）
- 📖 **ストーリー仕立て** ＋ **各編4通り＋αの複数エンディング**
- 💾 **手動セーブ（5枠）**：いつでもメニューから保存・ロード

ビルド不要。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

1. `index.html` を開く。
2. タイトルで **［▶ 物語をはじめる］**（または **［📁 つづきから］** でロード）。
3. 2つの物語から選ぶ：
   - **🇲🇿 モザンビーク編** … 数学Ⅰ・Ⅱ ＋ モザンビーク近現代史 ＋ ポルトガル語
   - **🇦🇴 アンゴラ編** … 数学A・B・C ＋ アンゴラ近現代史 ＋ ポルトガル語
4. テキストをクリックで読み進め、合間に **ポルトガル語・歴史・数学** の問いに答え、
   要所で **選択** を行います。
5. 全5章を読み終えると **エンディング** へ。

### 複数エンディングの仕組み

結末は2つの軸で分岐します。

- **📚 知識**（クイズの正答率）
- **🕯️ 眼差し**（物語中の選択で変化する、人々への向き合い方）

| | 眼差し 高 | 眼差し 低 |
| --- | --- | --- |
| **知識 高** | 記憶の守り手（トゥルー） | 冷徹な年代記者 |
| **知識 低** | 寄り添う証人 | 見習いの一歩 |

正答率が著しく低いと **「未完の書庫」**（バッドエンド）になります。
（クイズの選択肢は毎回 **ランダムに並び替え** られます。）

#### 🌟 隠しエンディング

**モザンビーク編・アンゴラ編の両方で最良の結末「記憶の守り手」に到達**すると、
ふたつの国の記憶をつなぐ隠しエンディング **「架け橋」** が解放されます
（2本目の編をクリアした瞬間に出現）。さらに、その到達が **全問正解** だった場合は、
隠しエンドに特別な最後の一文が追加されます。

解放後はタイトル画面に **［🌟 隠しエンド「架け橋」を観る］** ボタンが現れ、いつでも再生できます。
解放状況（エンディング図鑑）もタイトルに表示されます。実績は `localStorage` に保存されます。

### 💾 セーブ／ロード（手動・5枠）

- プレイ中はヘッダの **［≡ メニュー］** から、章間では **［📁 ここでセーブ］** から、
  いつでも **5つのスロット** に保存できます。
- 各スロットには「編・章・知識・眼差し・保存日時」が表示され、上書き／削除も可能。
- タイトルや編選択の **［📁 ロード］** からいつでも再開できます。
- データはブラウザの `localStorage` に保存されます（端末・ブラウザ単位）。

### 歴史

- **モザンビーク近現代史**：ポルトガル植民地 → FRELIMOの解放闘争 → 1975年独立（サモラ・マシェル）→ 内戦（vs RENAMO）→ 1992年ローマ和平協定。
- **アンゴラ近現代史**：奴隷貿易と植民地 → MPLA/FNLA/UNITAの三つ巴 → 1975年独立（アゴスティーニョ・ネト）と冷戦の代理戦争 → 2002年まで続いた内戦 → 石油による復興。

### ポルトガル語

あいさつ・数（数学の問題にも登場）・自由／平和／独立／選挙／復興などの歴史キーワードを、物語の文脈の中で学びます。

## ファイル構成

```
index.html              エントリーポイント
css/style.css           スタイル（80sシティポップ + ノベルUI）
js/game.js              ノベルエンジン（画面遷移・出題・選択・複数エンド・5枠セーブ）
js/audio.js             BGMコントローラ（再生・ミュート保存）
js/data/mozambique.js   モザンビーク編 ノベルデータ
js/data/angola.js       アンゴラ編 ノベルデータ
assets/bgm.mp3          BGM（ループ再生）
```

### BGMについて

`assets/bgm.mp3` をループ再生します。差し替えたい場合は同名のmp3を置くだけでOKです。
多くのブラウザは音声の自動再生を制限しているため、**最初のクリック（タップ）で再生が始まります**。
右上の 🔊 / 🔈 ボタンでいつでもオン／オフを切り替えられます。

## 物語・問題を追加／編集する

各編のデータは「ノード（場面）」の配列 `script` でできています。
エンジンを触らずに、物語・クイズ・選択肢を増やせます。

```js
// セリフ／ナレーション
{ t: "say",  who: "ドナ・マルタ", face: "👵🏿", text: "セリフ…" }
{ t: "narr", text: "情景描写…" }

// 学習メモ
{ t: "info", title: "この章のことば", items: ["…", "…"] }

// クイズ（qtype: "lang" 言語 / "hist" 歴史 / "math" 数学）
{
  t: "quiz", qtype: "math", subject: "数学Ⅰ・二次関数",
  q: "問題文", options: ["A","B","C","D"],
  answer: 1,                 // 正解の options インデックス（0始まり）
  explain: "解説文",
}

// 選択（heart で「眼差し」が増減＝エンディングに影響）
{
  t: "choice", text: "問いかけ…",
  choices: [
    { label: "選択肢A", heart: 1, who: "ドナ・マルタ", reply: "応答…" },
    { label: "選択肢B", heart: 0, reply: "応答…" },
  ],
}
```

エンディングの分岐条件は `js/game.js` の `computeEnding()`、
各編の結末文は各データファイルの `endings` で定義しています。
